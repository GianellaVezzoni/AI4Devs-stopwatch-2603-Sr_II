## Prompt 1

I want to build a stopwatch using only `index.html` and `script.js`.

Instead of doing something very basic, I’d like to create a small timer app with two modes:

- stopwatch
- countdown

For the stopwatch:

- start
- pause
- reset
- lap times

For the countdown:

- start
- pause
- reset
- inputs for minutes and seconds
- quick presets like 1, 5 and 10 minutes
- a visual progress indicator

Visually, I want it to feel modern and clean, not like a typical basic example:

- dark theme
- large readable timer
- clean buttons
- card-style layout
- responsive

Keep everything inside:

- `index.html` (HTML + CSS)
- `script.js` (logic)

Do not use any external libraries or frameworks.

Return the full code for both files.
